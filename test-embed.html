🧪 Chatwoot Embed - Página de Prueba

Esta página te permite probar la integración de Chatwoot mediante iframe y SDK. Úsala para verificar que tu configuración de CSP y CORS está correcta.

📋 Instrucciones Rápidas:

  1. Ingresa la URL de tu Chatwoot y el Website Token abajo
  2. Haz clic en "Cargar Widget"
  3. Si ves errores en la consola (F12), revisa la configuración de ALLOWED_FRAME_ANCESTORS
  4. Verifica que Chatwoot esté corriendo en la URL especificada
Lo encuentras en Settings → Inboxes → [Tu Widget] → Configuration
